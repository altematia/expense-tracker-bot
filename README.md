# Простой бот учёта расходов

Минимальный Telegram-бот на Python, `aiogram` и SQLite. Сервер и отдельная база не нужны: файл `expenses.sqlite3` создаётся рядом с ботом.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Установите зависимости: `python -m pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env` и вставьте токен в `BOT_TOKEN`.
4. Запустите: `python bot.py`

## Использование

Отправьте, например, `кофе 300` или `такси 1000`. Последнее число воспринимается как сумма в рублях; бот предложит десять категорий. После выбора он сохраняет в SQLite:

- Telegram ID пользователя;
- комментарий (`кофе`, `такси`);
- сумму;
- ключ и название выбранной категории;
- время записи.

`/cancel` отменяет ещё не подтверждённый расход.
